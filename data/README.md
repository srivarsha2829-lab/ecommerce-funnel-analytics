# Data

This directory is reserved for the e-commerce event data used in the analysis.

## Layout

- `raw/` contains the original downloaded files.
- `processed/` contains derived datasets created by the analysis.

The raw and processed datasets are intentionally ignored by Git so that large local files are not committed accidentally.

The public dataset source, download instructions, event definitions, and any filtering decisions will be added after the dataset is selected and inspected.
